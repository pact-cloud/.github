# Security policy

This policy applies to every repository in the pact-cloud organisation that does not carry its
own `SECURITY.md`.

PACT handles long-lived identity keys and private messages. If you find a vulnerability, report
it privately. **Do not open a public issue for security reports.**

Email mr.sumitagrawal.17@gmail.com with the subject `[pact security] <repository>`. Include a
reproduction if you can. You will get an acknowledgment within 72 hours and a status update at
least every 14 days until resolution.

Please give us reasonable time to ship a fix before public disclosure. Credit is given in release
notes unless you prefer otherwise.

The protocol's accepted trade-offs are recorded in the specification's security sections and are
not vulnerabilities by themselves. Where a repository states its own hardening status, that
statement is the one to read.
